api/ 目录说明
================================================

本目录用于存放各音乐平台所需的预编译 API 服务二进制。

这些二进制现已随源码仓库内置（已入库），打包（build.py）时会自动将
当前平台的二进制复制到产物 api/ 目录；直接运行源码或产物均无需手动准备。
只有在需要升级/更换版本时，才需自行从官方 GitHub Release 下载同名文件
覆盖本目录中的对应文件。程序启动时（或首次业务请求时）会自动按当前操作
系统选择并拉起对应的二进制。

各平台对应的二进制文件如下（均已在仓库内置；更新/替换时请保持
文件名一致，Windows 与 Linux 的文件名不同，Windows 带 .exe 后缀，Linux 无后缀）：

------------------------------------------------
一、网易云音乐（NeteaseCloudMusicApi-enhanced）
------------------------------------------------
  对应 GitHub 项目：
      https://github.com/NeteaseCloudMusicApiEnhanced/api-enhanced

  Windows x64:   ncm-api-win-x64.exe
  Linux   x64:   ncm-api-linux-x64

  内置版本取自上述项目 Releases；升级时下载同名文件覆盖本目录即可。

------------------------------------------------
二、QQ 音乐（qqmusic-api）
------------------------------------------------
  对应 GitHub 项目：
      https://github.com/chongya369/qqmusic-api-py

  Windows x64:   qqmusic-api-win-x64.exe
  Linux   x64:   qqmusic-api-linux-x64

  内置版本取自上述项目 Releases；升级时下载同名文件覆盖本目录即可。

------------------------------------------------
三、酷狗音乐（KuGouMusicApi）
------------------------------------------------
  对应 GitHub 项目：
      https://github.com/Lines98/KuGouMusicApi

  Windows x64:   kugou_api_win.exe
  Linux   x64:   kugou_api_linux

  内置版本为项目内置预编译包（已与 v1.5.1 兼容）；升级时下载同名文件覆盖。

------------------------------------------------
注意
------------------------------------------------
1. 更新/替换时请保证文件名与上表完全一致（含大小写与后缀），否则程序无法识别。
2. 二进制仅需保留当前使用平台的单个文件即可，也可同时放置多平台文件以便跨平台迁移。
3. 若对应二进制缺失，相关功能不可用，但不会影响程序其余流程。
